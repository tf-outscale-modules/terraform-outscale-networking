# Proposal

## Why

Planning in this module relies on Agent OS (`agent-os/standards/`, `agent-os/specs/`, `.claude/commands/agent-os/`), an older, unversioned copy of the rules now published as pinned OpenSpec stores. Sibling modules (vault, keycloak, gitlab-management) already moved to OpenSpec. Moving outscale-networking aligns it with them and gives the next changes a baseline contract to write delta specs against.

## What Changes

- Remove Agent OS: `agent-os/` (standards and the 2026-02-06 module spec) and `.claude/commands/agent-os/` (5 commands). Agent OS is replaced by the `quality`, `repository` and `terraform` OpenSpec stores referenced from `openspec/config.yaml`.
- Configure `openspec/config.yaml` (stores pinned to tags, outscale-networking `context`, per-artifact `rules` and `operations` guidance) and add `AGENTS.md` and `CLAUDE.md`.
- Install the `openspec-*` skills for Claude Code (`.claude/skills/`) and OpenCode (`.opencode/skills/`).
- Write the baseline capability specs under `openspec/specs/`, describing the module **as released today**.
- Tooling: pin the `openspec` CLI (and node) in `mise.toml`, add `spec-validate` and `spec-setup` tasks, add `scripts/openspec-setup.sh`, and validate specs in CI through `.gitlab/specs.yml` (job `validate:specs`).
- README "Contributing" points to the OpenSpec workflow.
- No change to any `.tf` file, input, output or resource: semver **patch**, shipped with the next tag. `CHANGELOG.md` stays generated by git-cliff.

## Capabilities

### New Capabilities
- `module-contract`: supported tooling and provider, no provider/backend blocks, required inputs, common tags, the output set.
- `core-network`: the Net, its subnets and the optional DHCP options.
- `internet-access`: the Internet Service, NAT services and standalone public IPs.
- `private-connectivity`: Net peerings and Net access points.
- `route-tables`: route tables, subnet associations, the main route table and routes by target type.
- `services`: load balancers and NICs.

## Impact

- Removed: `agent-os/`, `.claude/commands/agent-os/`.
- Added: `AGENTS.md`, `CLAUDE.md`, `.claude/skills/openspec-*`, `.opencode/skills/openspec-*`, `openspec/specs/*/spec.md` (on archive), `scripts/openspec-setup.sh`, `.gitlab/specs.yml`.
- Modified: `openspec/config.yaml`, `mise.toml` (openspec and node pins, two tasks), `.gitlab-ci.yml` (include), `.gitlab/global.yml` (`OPENSPEC_VERSION`), `.gitlab/pre-commit.yml` (cache keys), README "Contributing".
- Contributors need the stores registered once per machine (`mise run spec-setup`); CI needs no store, it only validates `openspec/`.
- Module consumers: none.
